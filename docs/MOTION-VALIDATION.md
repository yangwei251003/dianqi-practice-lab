# 48 个工位的三维动画验证

在正式版 Chrome 的生产构建中打开每个三维工位。固定相机，只截取画布中央区域，排除标题、提示和演示进度。每个工位对比两种工况、同一分段运行时的两帧，以及暂停后的两帧。

[逐工位运行与暂停记录](../evidence/motion/animated-rigs.json)中 48 项均达到图像变化判据。比较 RGB 任一通道相差至少 15/255 的像素。同一分段运行中有 446 至 27,430 个像素发生明显变化。48 个工位暂停后的对比均为零。这个检查用于检出画面是否真的变化。模型量、单位及事件顺序由独立的模型测试核对。
