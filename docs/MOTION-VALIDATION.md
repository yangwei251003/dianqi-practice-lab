# 实时三维与交互动效专项验证 · 2026-11-19

本次把两件事分开验证：设备运行时，三维画布本身有没有变化；学生操作网页时，动效是否真的带到了正确位置。页面上的字在变、倒计时在走、相机能旋转，都不能单独算作设备在动。

## 48 个工位怎样验证

- 在已安装的桌面 Chrome 中打开生产构建的每个三维工位，固定相机，只截取画布中央区域，排除标题、演示进度、提示文字及鼠标。每个工位分别比较两种工况、同一分段运行中的两帧，以及全部暂停后的两帧。
- [逐工位画布对比原始记录](../evidence/motion/animated-rigs.json)：48/48 通过。取 RGB 任一通道差值至少 15/255 的像素计数；同一分段内有 446 至 27,430 个像素发生明显变化。48 个工位暂停后都没有超过该阈值的变化。运行和暂停都用同一判据；像素数量不衡量美感或物理精度。
- 独立核对模型、状态和可见通道。运行全部 346 项自动检验，包含泵与管网的交点、园区并网点功率账、RC 过程、变流器平均量、边沿计数、演示分段及 26 个动效应用地址。每个工位的实际操作与迁移另见[建设矩阵](COURSES.md)。播放演示不能通过实操考核。

## 26 种动效怎样验证

逐项实际悬停、点按、按键或改变工况，再验证示例的可见结果；另从 26 张卡逐一进入实训台，检查滚动目标及真实键盘焦点。最后检查复制不被允许时的可选中文本、取样冻结/写入/恢复、目录筛选与跳站、窄屏和减少动效。每轮共 56 项，失败项、浏览器版本、测量时间均保留在结果中。
