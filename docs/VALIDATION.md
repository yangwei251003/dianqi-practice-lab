## 验收口径

四类模型检验与浏览器实操独立记录，不拿播放动画、构建成功或加载页面代替课程完成。模型检验对照固定参考值、解析解或事件时序；浏览器在真实控件上操作、检查读数/节点与模型是否一致，再进入独立迁移工况。浏览器结果只覆盖所列平台；WebKit 不等于 Safari 真机，桌面触控模拟不等于手机实机。软件渲染验证可交互性，不承诺真机 GPU 帧率。

## 待专业复核

本项目未获得电气现场安全、保护、机械或交通专业人员签核；表中“待专业复核”仅供仿真预习。未做实物对照测绘、现场接线、PLC 下载、电网/充电机连接、校准或厂方认证。资料链接/厂家页面可能更新，维护时复查对应版本及适用条件。

## 平台与网络限制

Windows WebKit 在多个图形浏览器并行启动的测试里曾发生页面或三维初始化超时；单独重新运行后，四个代表工位的主任务及迁移通过。较慢设备可切换工位内的二维视图；不把软件渲染结果当真机性能承诺。见[厂家链接读回与备用入口](ATTRIBUTION.md)。
